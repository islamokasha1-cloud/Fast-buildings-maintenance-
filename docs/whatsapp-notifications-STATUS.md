## 1) الهدف
إرسال إشعارات واتساب في نظام صيانة/مشتريات المباني السريعة (SPA + Firebase):
- **إشعار الفني** بالبلاغ المُسنَد إليه (عند تغيّر حقل `tech` في مستند البلاغ).
- **إشعار المعنيين بطلبات الشراء**: طلب جديد، أو طلب ينتظر **اعتمادهم حسب صلاحياتهم**
  (توجيه حسب حالة `status` في `global_purchases` → الدور المطلوب).

## 2) قرارات معمارية ثابتة
- المشروع: **`fast-buildings`** (Firebase). النظام client-side بالكامل حالياً.
- واتساب يحتاج **طبقة خادمية** → **Firebase Cloud Functions (2nd gen)** + Secret Manager.
- التصميم: مشغّلات Firestore → طابور **`wa_outbox`** (منع تكرار + إعادة محاولة) → مُرسِل
  ينادي WhatsApp Cloud API. **محايد تجاه المزوّد**.
- يجب إضافة حقول `phone` + `waOptIn` إلى `technicians` و`USERS` (غير موجودة حالياً).
- الأسرار في Secret Manager/متغيّرات الخادم، **لا في المتصفح**.
