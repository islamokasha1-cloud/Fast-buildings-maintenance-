- التصميم: مشغّلات Firestore → طابور **`wa_outbox`** (منع تكرار + إعادة محاولة) → مُرسِل
  ينادي WhatsApp Cloud API. **محايد تجاه المزوّد**.
- يجب إضافة حقول `phone` + `waOptIn` إلى `technicians` و`USERS` (غير موجودة حالياً).
- الأسرار في Secret Manager/متغيّرات الخادم، **لا في المتصفح**.
