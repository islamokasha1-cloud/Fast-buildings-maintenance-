# إعلان فيديو الشركة (Remotion)

مشروع [Remotion](https://www.remotion.dev/) في `remotion/` ينتج إعلاناً
تعريفياً لـ**شركة المباني السريعة للمقاولات**: عربي RTL، 1920×1080،
30 إطار/ثانية، تسعة مشاهد.

اقرأ `remotion/README.md` أولاً — فيه جدول المشاهد وتفاصيل كل جزء.

## الأوامر

كلها تُنفَّذ من داخل `remotion/`:

```bash
npm start                          # معاينة تفاعلية (Remotion Studio)
npm run render                     # 1920×1080 → out/company-announcement.mp4
npm run render:4k                  # 3840×2160 → out/company-announcement-4k.mp4
npm run music                      # إعادة توليد موسيقى الخلفية
node scripts/capture-platform.mjs  # إعادة التقاط لقطات النظام
```

الرندر بدقة 4K يتجاوز عشر دقائق — شغّله في الخلفية.

ومن جذر المشروع (خارج `remotion/`):

```bash
npm install --no-save playwright-core ffmpeg-static chart.js@4.4.1   # في أمرٍ واحد — --no-save يحذف ما لم يُذكر
node promo-video.mjs --probe  # لقطاتٌ فقط بلا تسجيل (~دقيقتان) — راجعها بالعين قبل الرندر
node promo-video.mjs          # جولة شاشات المنصة الحقيقية (تسجيل شاشة في Chromium)
node promo-assemble.mjs --4k  # الفيلم الكامل 4K: افتتاحية الإعلان + الجولة + الختام
node promo-video.mjs --probe --topic ai   # فصول الذكاء الاصطناعي الستّة وحدها — لقطاتٌ بلا تسجيل
node higgsfield-shots.mjs                 # لقطاتٌ مولَّدة لمشاهد AiFacilities (اختيارية — تحتاج اعتماد Higgsfield)
node promo-assemble.mjs --film ai --4k    # فيلم «الذكاء الاصطناعي في إدارة المرافق» 4K
```

**فيديو الذكاء الاصطناعي** تركيبةٌ مستقلّة `src/AiFacilities.tsx` (نصوصُها في `defaultProps`
بـ`src/Root.tsx`)؛ لا تعدّل مشاهدَ الإعلان من أجله. التجميعُ قائمةُ مقاطع (`FILMS` في
`promo-assemble.mjs`) — أضف فيلماً بقائمةٍ جديدة، لا بنسخ السكربت.

الجولةُ ١٩ فصلاً تُرقَّم تلقائياً بترتيبها في `CHAPTERS`، ولبعضها مشهدٌ «عن قرب»
في موضعه (`after`): نافذةُ طلب الشراء بمراحله داخل فصل المشتريات، بطاقةُ
المشروع داخل إدارة المشاريع، والملخّصُ التنفيذيُّ وفرزُ البلاغ في فصل الذكاء
الاصطناعي. **نداءاتُ الذكاء الاصطناعي تُلبّى بردودٍ مُعدَّة** (`AI_CANNED`) والخطوطُ
وChart.js من نسخٍ محلية — فالشاشةُ حقيقيةٌ والشبكةُ معدومة.

`promo-assemble.mjs` يستعمل تركيبة `PlatformIntro` افتتاحيةً للفيلم الأصليّ، ويقتطع الختام
من `CompanyAnnouncement` بأرقام إطاراتٍ ثابتة في رأسه (`OUTRO`) — **إن غيّرت
ترتيب المشاهد أو مدتها في `src/CompanyAnnouncement.tsx` فحدِّث هذا الثابت**،
وإلا اقتطع مشهداً آخر بلا أن يشتكي شيء.

**لا تكتب رسالة «شرح المنصة» في مشاهد الإعلان.** الإعلان عامٌّ عن الشركة
وقطاعاتها؛ وافتتاحيةُ عرض المنصة تركيبةٌ مستقلّة (`src/PlatformIntro.tsx`)
نصوصُها في `defaultProps` بـ`src/Root.tsx`.

## أين تعدّل ماذا

| المطلوب | الملف |
|---------|-------|
| الاسم والتاجلاين والتواصل ومدة الفيديو | `src/Root.tsx` |
| المشاهد وترتيبها في الخط الزمني | `src/CompanyAnnouncement.tsx` |
| العملاء ولوجوهاتهم | `src/clients.ts` + `public/clients/` |
| قطاعات الأعمال الثلاثة وخدماتها | `src/divisions.ts` |
| الشهادات والتصنيف | `src/certifications.ts` |
| المناطق المخدومة | `src/regions.ts` |
| صور المشاريع | `src/photos.ts` + `public/photos/` |
| الألوان وتوكنات التصميم | `src/theme.ts` |
| الأيقونات (SVG خطية) | `src/Icons.tsx` |
| سنة التأسيس | `src/company.ts` |

## قواعد لا تُخالَف

**مدة الفيديو والموسيقى مرتبطتان.** عند تغيير `durationInFrames` في
`src/Root.tsx`، حدِّث `DURATION` في `scripts/make-music.py` بالقيمة نفسها
بالثواني ثم شغّل `npm run music` — وإلا انتهت الموسيقى قبل الفيديو.

**الشهادات: السارية فقط.** الإعلان موجّه لجهات حكومية تتحقق. الشهادة
المنتهية تضرّ المصداقية أكثر مما تنفع. ولا تُدرج بيانات حساسة من وثائق
الشهادات (الرقم الوطني الموحد، اسم المالك، أرقام الشهادات، أكواد QR).

**المناطق: ما تعمل فيه الشركة فعلاً.** الخريطة ادّعاء جغرافي يسهل
التحقق منه — لا تضف منطقة لمجرد أن مقر أحد العملاء فيها.

**الأرقام مشتقّة لا مكتوبة.** أرقام مشهد «لماذا المباني السريعة» تُحسب
تلقائياً من `clients` ومن `FOUNDED_YEAR`. لا تكتبها يدوياً.

**لقطات النظام تحوي بيانات عرض توضيحية** يولّدها
`scripts/capture-platform.mjs` — ليست سجلات تشغيل حقيقية. لا تبنِ عليها
أي ادعاء رقمي في نصوص الإعلان.

## لغة التصميم

مأخوذة من توكنات CSS في `index.html` (منصة الشركة نفسها): خلفية رمادية
`#eef2f7`، كروت بيضاء بحدود `#dde3ed` وشرائط علوية ملوّنة، أزرق كحلي
`#1b3a6b`، أخضر `#0a7c59`، كهرماني `#a06010`. خطوط Cairo و Tajawal
محلية في `public/fonts`. أيقونات SVG خطية — **لا إيموجي**.

التخطيط RTL، لذا العناوين على اليمين وشعار الشركة الثابت أسفل اليسار.

## التحقق قبل التسليم

ارندر لقطة ثابتة للمشهد المعدَّل **وانظر إليها** قبل رندر الفيديو كاملاً:

```bash
npx remotion still CompanyAnnouncement out/check.png --frame=830
```

أرقام الإطارات لكل مشهد في جدول `README.md`. بعد رندر الفيديو تحقق من
المدة ووجود مسار الصوت:

```bash
ffprobe -v error -show_entries stream=codec_type,width,height \
  -show_entries format=duration -of default=noprint_wrappers=1 \
  out/company-announcement.mp4
```
