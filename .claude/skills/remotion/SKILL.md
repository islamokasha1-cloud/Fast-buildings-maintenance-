# إعلان فيديو الشركة (Remotion)

مشروع [Remotion](https://www.remotion.dev/) في `remotion/` ينتج إعلاناً
تعريفياً لـ**شركة المباني السريعة للمقاولات**: عربي RTL، 1920×1080،
30 إطار/ثانية، تسعة مشاهد.

اقرأ `remotion/README.md` أولاً — فيه جدول المشاهد وتفاصيل كل جزء.

## الأوامر

كلها تُنفَّذ من داخل `remotion/`:

```bash
npm start                          # معاينة تفاعلية (Remotion Studio)
npm run render                     # 1920×1080 → out/company-announcement.mp4
npm run render:4k                  # 3840×2160 → out/company-announcement-4k.mp4
npm run music                      # إعادة توليد موسيقى الخلفية
node scripts/capture-platform.mjs  # إعادة التقاط لقطات النظام
```

الرندر بدقة 4K يتجاوز عشر دقائق — شغّله في الخلفية.

## قواعد لا تُخالَف

**مدة الفيديو والموسيقى مرتبطتان.** عند تغيير `durationInFrames` في
`src/Root.tsx`، حدِّث `DURATION` في `scripts/make-music.py` بالقيمة نفسها
بالثواني ثم شغّل `npm run music` — وإلا انتهت الموسيقى قبل الفيديو.

**الشهادات: السارية فقط.** الإعلان موجّه لجهات حكومية تتحقق. الشهادة
المنتهية تضرّ المصداقية أكثر مما تنفع. ولا تُدرج بيانات حساسة من وثائق
الشهادات (الرقم الوطني الموحد، اسم المالك، أرقام الشهادات، أكواد QR).

**المناطق: ما تعمل فيه الشركة فعلاً.** الخريطة ادّعاء جغرافي يسهل
التحقق منه — لا تضف منطقة لمجرد أن مقر أحد العملاء فيها.

**الأرقام مشتقّة لا مكتوبة.** أرقام مشهد «لماذا المباني السريعة» تُحسب
تلقائياً من `clients` ومن `FOUNDED_YEAR`. لا تكتبها يدوياً.

**لقطات النظام تحوي بيانات عرض توضيحية** يولّدها
`scripts/capture-platform.mjs` — ليست سجلات تشغيل حقيقية. لا تبنِ عليها
أي ادعاء رقمي في نصوص الإعلان.

## لغة التصميم

مأخوذة من توكنات CSS في `index.html` (منصة الشركة نفسها): خلفية رمادية
`#eef2f7`، كروت بيضاء بحدود `#dde3ed` وشرائط علوية ملوّنة، أزرق كحلي
`#1b3a6b`، أخضر `#0a7c59`، كهرماني `#a06010`. خطوط Cairo و Tajawal
محلية في `public/fonts`. أيقونات SVG خطية — **لا إيموجي**.

التخطيط RTL، لذا العناوين على اليمين وشعار الشركة الثابت أسفل اليسار.

## التحقق قبل التسليم

ارندر لقطة ثابتة للمشهد المعدَّل **وانظر إليها** قبل رندر الفيديو كاملاً:

```bash
npx remotion still CompanyAnnouncement out/check.png --frame=830
```

أرقام الإطارات لكل مشهد في جدول `README.md`. بعد رندر الفيديو تحقق من
المدة ووجود مسار الصوت:

```bash
ffprobe -v error -show_entries stream=codec_type,width,height \
  -show_entries format=duration -of default=noprint_wrappers=1 \
  out/company-announcement.mp4
```
