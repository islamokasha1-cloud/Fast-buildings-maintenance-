# إعلان فيديو — شركة المباني السريعة للمقاولات (Remotion)

مشروع [Remotion](https://www.remotion.dev/) لإنتاج إعلان فيديو تعريفي للشركة
بدقة **1920×1080** ومدة **54 ثانية** (30 إطار/ثانية)، **بنفس لغة تصميم منصة
المباني السريعة**: خلفية رمادية (`#eef2f7`)، كروت بيضاء بحدود ناعمة وشرائط
علوية ملوّنة، بانر `page-hero` أزرق كحلي، وأيقونات **SVG خطية** بدل الإيموجي.
كل التوكنات (ألوان/حدود/ظلال) مستخرجة من متغيّرات CSS في `index.html`.

## المشاهد

| # | المشهد | المدة |
|---|--------|-------|
| 1 | ظهور الشعار واسم الشركة | 4 ثوانٍ |
| 2 | من نحن — تعريف موجز بالشركة | 5 ثوانٍ |
| 3 | قطاعات أعمالنا — المقاولات وإدارة المرافق والمعادن | 8 ثوانٍ |
| 4 | عملاؤنا — لوجو واسم كل عميل | 7 ثوانٍ |
| 5 | نطاق أعمالنا — خريطة المناطق | 5 ثوانٍ |
| 6 | منصتنا الرقمية — لقطات من النظام | 6 ثوانٍ |
| 7 | شهاداتنا واعتماداتنا | 6 ثوانٍ |
| 8 | لماذا نحن — أرقام وقيمة | 5 ثوانٍ |
| 9 | الختام والدعوة للتواصل | 8 ثوانٍ |

> عند تغيير مدة الفيديو في `src/Root.tsx`، حدِّث `DURATION` في
> `scripts/make-music.py` وأعد توليد الموسيقى حتى لا تنتهي قبل الفيديو.

## التشغيل

```bash
cd remotion
npm install
```

### معاينة تفاعلية (Remotion Studio)

```bash
npm start
```

ثم افتح المتصفح على العنوان الظاهر (افتراضياً http://localhost:3000).

### إنتاج الفيديو (رندر)

```bash
npm run render      # 1920×1080 — للواتساب والاستخدام العام
npm run render:4k   # 3840×2160 — للشاشات الكبيرة والعرض التقديمي
```

الناتج في `remotion/out/`. المشروع كله متجهي (نصوص وأشكال CSS)، لذلك
يُرندر بأي دقة دون فقدان حدّة — لعرضٍ على شاشة 65 بوصة فأكبر استخدم
نسخة 4K.

## التخصيص

- **الاسم والشعار والتاجلاين**: عدّل `defaultProps` في `src/Root.tsx`،
  أو مرّرها من واجهة الـ Studio.
- **الألوان**: `src/theme.ts` (توكنات المنصة: `bg`, `surface`, `border`,
  `primary`, `accent`, `warn`…).
- **الأيقونات**: `src/Icons.tsx` — أيقونات SVG خطية قابلة لإعادة الاستخدام.
- **الشهادات**: `src/certifications.ts` — التصنيف الرسمي والمواصفات
  الدولية. **لا تُدرج إلا الشهادات السارية**؛ الشهادة المنتهية في إعلان
  موجّه لجهات حكومية تضرّ المصداقية أكثر مما تنفع. ولا تُدرج بيانات
  حساسة (الرقم الوطني الموحد، اسم المالك، أرقام الشهادات).
- **المناطق**: `src/regions.ts` — أضف منطقة باسمها وإحداثياتها.
  الملف يحوي إحداثيات المدن السعودية جاهزة. **أضف ما تعملون فيه فعلاً**
  فالخريطة ادّعاء جغرافي يسهل التحقق منه.
- **العملاء**: `src/clients.ts` — أضف عميلاً بسطر واحد، وضع لوجوه في
  `public/clients/`. التخطيط يتكيّف مع العدد تلقائياً (بطاقة كبيرة للواحد
  أو الاثنين، وشبكة لما زاد)، وإن لم يتوفر لوجو تظهر أيقونة الجهة بدلاً منه.
- **قطاعات الأعمال**: `src/divisions.ts` — القطاعات الثلاثة وخدمات
  كل قطاع. الألوان والأيقونات في `DIVISION_STYLE` داخل
  `src/CompanyAnnouncement.tsx`.
- **بيانات التواصل** (هاتف/موقع): تُمرَّر عبر `phone` و`website` في
  `defaultProps` (تظهر في مشهد الختام عند تعبئتها).
- **سنة التأسيس**: `FOUNDED_YEAR` في `src/company.ts` — تُحتسب منها
  سنوات الخبرة تلقائياً.

### أرقام مشهد «لماذا المباني السريعة؟»

الأرقام الثلاثة **مشتقّة تلقائياً** ولا تُكتب يدوياً:

| الرقم | مصدره |
|-------|-------|
| عدد الجهات | طول مصفوفة `clients` |
| عدد القطاعات | القيم الفريدة لحقل `sector` |
| سنوات الخبرة | السنة الحالية ناقص `FOUNDED_YEAR` |

فإضافة عميل جديد تُحدِّث الرقمين الأولين دون أي تعديل إضافي.

## الموسيقى

موسيقى الخلفية في `public/audio/background.mp3` **مقطوعة أصلية مؤلَّفة
برمجياً** عبر `scripts/make-music.py`، فلا تخضع لأي ترخيص خارجي.

```bash
npm run music     # إعادة توليد المقطوعة بعد تعديل السكربت
```

- **مستوى الصوت**: عدّل `musicVolume` في `src/Root.tsx` (من 0 إلى 1،
  والافتراضي 0.7). القيمة 0 تُنتج فيديو صامتاً.
- **استبدالها بمقطوعة أخرى**: ضع ملفك باسم
  `public/audio/background.mp3` — لا حاجة لأي تعديل في الكود. تأكد من
  امتلاكك حقوق استخدام أي مقطوعة خارجية.
- **تعديل المزاج**: غيّر `PROGRESSION` أو `BPM` في السكربت.
- **مدة ومخرَج مختلفَين**: `MUSIC_DURATION` و`MUSIC_OUT` (ومسار ffmpeg عبر
  `FFMPEG_BIN`) متغيّراتُ بيئةٍ تتجاوز الافتراضات دون تعديل السكربت —
  يستعملها `promo-assemble.mjs` ليؤلّف فراشاً بطول الفيلم المجمَّع.
  الافتراضُ يبقى ٥٤ ثانية، أي مدةَ الإعلان في `src/Root.tsx`.

## الفيلم المجمَّع (إعلان + جولة الشاشات)

`promo-assemble.mjs` في جذر المشروع يجمع **تركيبة `PlatformIntro`** ومشهد
**الختام (١٣٨١–١٦٢٠)** من هذا الإعلان مع جولةِ شاشات المنصة الحقيقية التي
يسجّلها `promo-video.mjs`، بذوبانٍ عند الوصلتين وفراشٍ موسيقيٍّ واحدٍ متّصل:

```bash
node promo-assemble.mjs              # → dist-video/promo-film.mp4
node promo-assemble.mjs --skip-body  # أعِد التجميع دون إعادة تسجيل الجولة
```

المشهدان يُرندَران بـ`musicVolume: 0` لأن الموسيقى تُفرَش على الفيلم كلِّه
دفعةً واحدة. **أرقامُ إطارات الختام مشتقّةٌ من `Sequence` في
`src/CompanyAnnouncement.tsx`** — فإن غيّرت ترتيبَ المشاهد أو مدتَها،
حدِّث `OUTRO` في رأس `promo-assemble.mjs`.

### `PlatformIntro` — افتتاحيةُ عرض المنصة

تركيبةٌ مستقلّةٌ في `src/PlatformIntro.tsx` (٥ ثوانٍ): شعارٌ كبير، اسمُ الشركة،
وسطرٌ يوضّح أن العرض **شرحٌ للمنصة** لا إعلانٌ عن الشركة. نصوصُها في
`defaultProps` داخل `src/Root.tsx`.

**لماذا مشهدٌ منفصلٌ لا تعديلٌ على مشهد افتتاح الإعلان:** الإعلانُ عامٌّ عن
الشركة وقطاعاتها الثلاثة، وهذا عرضٌ موضوعُه المنصةُ وحدَها. لو كُتب «عرضٌ
لشرح المنصة» في مشهد الإعلان لصار الإعلانُ يعد بما لا يعرضه. المشهدان
يتشاركان لغةَ التصميم ويفترقان في الرسالة.

## الخطوط

خطوط **Cairo** و**Tajawal** منزّلة محلياً داخل `public/fonts` وتُحمَّل بلا
اتصال بالإنترنت وقت الرندر (عبر `src/FontLoader.tsx`) لضمان ثبات النتيجة.

## الشعار

الشعار منسوخ من `logo.png` في جذر المشروع إلى `public/logo.png`. عند تحديث
شعار الشركة، استبدل الملف في `public/logo.png`.

## لقطات المنصة

لقطات نظام إدارة المرافق في `public/platform/` تُلتقط آلياً:

```bash
node scripts/capture-platform.mjs
```

يشغّل السكربت `index.html` في Chromium مع **Firestore وهمي في الذاكرة**
(لا يلمس بيانات الإنتاج إطلاقاً) ويتجاوز تسجيل الدخول، ثم يلتقط
الصفحات المحددة في مصفوفة `SCREENS`.

### بيانات العرض

قبل الالتقاط يملأ السكربت النظام بـ **بيانات عرض توضيحية** (دالة
`SEED_DEMO_DATA`) حتى لا تظهر الشاشات فارغة. هذه البيانات تُولَّد بدالة
`mk()` الخاصة بالنظام فتطابق بنيته، وتستخدم أسماء المباني وأنواع الأعمال
والمشرفين من إعداداته الفعلية.

**هي توضيح لعمل الواجهة وليست سجلات تشغيل حقيقية.** ضُبطت لتعكس تشغيلاً
منضبطاً دون مبالغة: كل بلاغ تجاوز نافذته المستهدفة يكون مغلقاً، فتبقى
البلاغات المفتوحة داخل الزمن المستهدف.

لاستبدال اللقطات بأخرى من نظام الإنتاج — وهو الأفضل — ضع الصور بالأسماء
نفسها في `public/platform/` دون تعديل الكود.

## خريطة المناطق

`src/saudiRegions.json` يحوي حدود المناطق الإدارية الثلاث عشرة، مستخرجة
من بيانات **Natural Earth** (`ne_10m_admin_1_states_provinces`، مجال عام)
ومبسّطة بخوارزمية دوغلاس-بويكر إلى ~8 كيلوبايت.

يرسم `src/SaudiMap.tsx` الحدود ويلوّن المناطق المخدومة بلون الهوية،
اعتماداً على حقل `region` في `src/regions.ts` — فيجب أن يطابق الاسم
هناك اسم المنطقة في ملف الحدود.
