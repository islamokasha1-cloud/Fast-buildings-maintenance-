# لقطاتُ مشاهد «الذكاء الاصطناعي في إدارة المرافق»

يكتب `higgsfield-shots.mjs` (في جذر المشروع) هنا خمسَ لقطاتٍ مولَّدة —
`problem.mp4` · `building.mp4` · `camera.mp4` · `robots.mp4` · `predictive.mp4` —
وسجلَّ `manifest.json` يقرؤه `promo-assemble.mjs --film ai` ويمرّره خاصيّةَ
`clips` إلى تركيبة `AiFacilities`. الملفّاتُ خارج git (وسائطُ لا كود).

**الغيابُ لا يُعطّل شيئاً:** كلُّ مشهدٍ يُرسم متجهياً إن لم تكن لقطتُه هنا.
ولاستبدال لقطةٍ بتصويرٍ حقيقيّ من الموقع — وهو الأفضل — ضع الملفَّ بالاسم
نفسِه وأضف سطرَه في `manifest.json`:

```json
{ "clips": { "robots": "ai/robots.mp4" } }
```

المواصفات: 16:9 · 1080p فأعلى · بلا نصٍّ ولا شعاراتٍ داخل اللقطة · ١٠–١٢ ثانية.
