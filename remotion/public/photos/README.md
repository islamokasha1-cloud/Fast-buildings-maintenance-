# صور المشاريع والمواقع

ضع الصور هنا ثم أضف كل صورة في `src/photos.ts`.

## المواصفات المفضّلة

- **النسبة**: 16:9 أفقية (تُقصّ تلقائياً لتملأ الإطار)
- **العرض**: 1600 بكسل فأكثر — الفيديو يُرندر بدقة 4K
- **الصيغة**: JPG أو PNG، بلا علامات مائية أو تواريخ مطبوعة

## ما يصلح للإعلان

- ورش التصنيع والحدادة أثناء العمل
- فنيون أثناء التنفيذ (بزي الشركة إن أمكن)
- مواقع إنشاء وترميم، ومبانٍ بعد التسليم
- معدات وآليات الشركة

## ما يُتجنّب

- صور فيها وجوه دون موافقة أصحابها
- لافتات أو شعارات جهات أخرى بما يوحي بعلاقة غير قائمة
- لقطات تُظهر بيانات أو مستندات حساسة
