# فيلم «الذكاء الاصطناعي في إدارة المرافق» — ملفات جاهزة

فرعٌ للملفات الثقيلة فقط. **لا يُدمَج في `main`** — وجودُه هنا لتحميل الفيديو من
واجهة GitHub. اللقطاتُ الستُّ مولَّدةٌ من Higgsfield (Seedance 2.5) بشعار الشركة
مرجعاً، والمونتاجُ (العناوين العربية · الموسيقى · الختام) من تركيبة `AiFilm` في Remotion.

| الملف | الدقة | المدة | الحجم |
|---|---|---|---|
| `ai-film-4k.mp4` | 3840×2160 (للشاشة 60 بوصة) | 0:54 | ~٨٣ م.ب |
| `ai-film-1080.mp4` | 1920×1080 (للواتساب والعرض العامّ) | 0:54 | ~٤٩ م.ب |

نسخةُ 4K مُعاد ترميزُها (CRF 23) لتدخل تحت حدّ GitHub للملفّ الواحد؛ اللقطاتُ
المصدرية 720p فلا فرقَ مرئيّاً عن الرندر الخام.

يُعاد توليدُهما من فرع العمل (`claude/ai-facilities-management-video-nvzp07` ثم `main`):

```bash
NODE_USE_ENV_PROXY=1 node higgsfield-shots.mjs --parallel --force   # مدفوع — ست لقطات (~$8)
cd remotion && npm install && npm run render:ai && npm run render:ai:4k
```

بعد تنزيل الملفات يمكن حذفُ هذا الفرع بلا أثر:
`git push origin --delete media/ai-film`
