# فحوص نظام هيل

هياكل اختبار تُشغّل الكود الحقيقي المستخرَج من `index.html` بلا تعديل حرف —
لا تقرأه، بل **تُنفّذه**. بُنيت أثناء جولات `v18.9ng` → `v18.9nl` ، ووجدت
نصف الأخطاء التي لم تكشفها القراءة.

## التشغيل

### الطريقة الموصى بها — على GitHub بلا جهازك ولا طرفية
انسخ `hail-tests.yml` إلى `.github/workflows/hail-tests.yml` في المستودع.
تعمل الفحوص تلقائياً عند كل رفع لـ `index.html` ، وتُظهر ✅ أو ❌ بجانب كل
commit. ولو فشل فحص، يصلك بريد من GitHub تلقائياً.
يمكن تشغيلها يدوياً في أي وقت: تبويب **Actions** ← الـ workflow ← **Run workflow**.

### على جهاز فيه طرفية
```bash
cd hail-tests && bash run.sh
```

## الملفات

| الملف | يفحص | وجد فعلاً |
|---|---|---|
| `verify-wa.js` | توزيع الاستلام: المستودع = المستلم − المباشر، قصر المباشر، الفجوة | تحذير كاذب يومض أثناء الكتابة |
| `verify-del.js` | عكس المخزون عند الحذف: الإشارة، التجميع بـ `itemId` ، الصافي | — (بُني بعد الإصلاح) |
| `verify-log.js` | إشارة وكمية كل نوع حركة في السجل | تأكيد أن `adjustDelta` مصدر الحقيقة |
| `verify-nl.js` | النقر المزدوج + تعديل الرصيد الطازج + ثابت `Δ = الجديد − الحي` | `189` تركيبة |
| `verify-kpi.js` | أن `purchase-kpi.js` يركّب نفسه ويحسب | `14` فحصاً |
| `map_writers.py` | **خريطة الكُتّاب** — من يكتب في `currentQty` وبأي نمط | `14` دالة، `22` موضعاً |
| `probe_guards.py` | حماية النقر المزدوج والتسابق لكل كاتب | رشّح `9` مشتبهاً بهم |
| `check_nl.py` | قائمة ما قبل التسليم: `node --check` ، توازن `<div>` ، الإصدار، `?v=` | — |

## قاعدتان تعلّمناهما بالثمن

1. **القراءة لا تُثبت شيئاً.** خطأ إشارة عكس المخزون كان فوقه تعليق واثق يقول
   «موجب لأننا نُعيد للمخزون» — وهو خاطئ. من يقرأ يُصدّقه. من يُشغّل يكشفه.
2. **الترشيح ليس حكماً.** `probe_guards.py` رشّح `9` دوال؛ تبيّن أن بعضها بريء.
   كل مشتبه به يُحقَّق فيه فردياً قبل الإدانة.

## المتبقي (لم يُبنَ بعد)

- **فحص الثوابت العشوائي للدورة الكاملة**: أنشئ → راجع → استلم → احذف ←
  المخزون يجب أن يعود لنقطة البداية بالضبط. آلاف السيناريوهات العشوائية.
  *هذا كان سيكشف مضاعفة الحذف من أول محاولة.*
- **فاحص التناقضات** (صفحة داخل النظام): رصيد كل صنف = مجموع حركاته؟
  أثر كل طلب محذوف = صفر؟ المستودع + المباشر = المستلم في كل سند؟
  `receivedQty` = مجموع سنداته؟ رصيد سالب؟ حركات يتيمة؟
  **تنبيه**: لا يكشف المضاعفة بالنقر المزدوج — إذ يُكتب السجل مرتين فيتوازن.
